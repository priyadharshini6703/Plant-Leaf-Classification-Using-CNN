# Plant Leaf Classification Using CNN

## Description

A deep learning project that classifies plant leaf images into different categories using a Convolutional Neural Network (CNN).

## Technologies Used

* Python
* TensorFlow
* Keras
* OpenCV
* NumPy
* Matplotlib

## Dataset

The dataset contains plant leaf images organized into different categories, including Apple, Berry, Guava, and Orange.

## Methodology

* Image preprocessing
* Image resizing and normalization
* Dataset preparation
* CNN model development
* Model training and evaluation
* Plant leaf classification

## Model

A Convolutional Neural Network (CNN) is used to learn visual features from plant leaf images and classify them into their respective categories.

## Result

The trained CNN model classifies plant leaf images into the corresponding plant categories based on the visual features learned during training.
